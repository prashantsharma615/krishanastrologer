# Krishan Astrologer – कृष्ण ज्योतिषी

Vedic astrology web app (PWA) in **Hindi and English**.

- Exact Vedic kundli: planet positions computed astronomically (sidereal, Lahiri ayanamsa), North Indian chart, nakshatra & pada
- Vimshottari Mahadasha / Antardasha with dates
- Problem → solution: 12 life problems (job, business, money, marriage, love, health, education, family, court case, foreign, children, property) answered from the person's own chart — cause, timing, remedies (mantra + upay) and practical steps
- Works offline, installable, ready to package for Google Play with PWABuilder
- All calculation happens on the device; no data is collected

Live: https://krishanastrologer.netlify.app/

Readings are traditional Jyotish interpretation offered as guidance, not guaranteed predictions.
